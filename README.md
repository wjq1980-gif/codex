# 可口可乐健康话题短视频

这是一个可直接在浏览器中播放的 9:16 竖屏短视频成片页面，主题为“可口可乐健康吗？”。内容采用科普和风险提示口吻：可口可乐可以偶尔享用，但不把甜饮描述成健康饮品。

## 文件说明

- `index.html`：可播放的动画成片，包含竖屏画面、气泡动效、分镜字幕和进度条。
- `video-script.md`：30 秒分镜脚本、旁白字幕和发布文案。
- `scripts/validate.js`：基础校验脚本，确认核心文案和无障碍降动效设置存在。

## 预览方式

直接用浏览器打开 `index.html`。如需导出为视频，可使用系统录屏工具录制浏览器窗口，或在本地安装视频导出工具后录制 30 秒完整循环。

## 内容原则

为了避免误导性健康宣称，视频没有把可口可乐包装成“健康饮品”，而是强调少量、低频、日常补水优先选择水或无糖饮品。
